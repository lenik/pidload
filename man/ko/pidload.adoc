== 이름

pidload - 프로세스 부하 및 장치/네트워크 트래픽 감시

== 개요

*pidload* [_OPTION_]... [_NAME_]...

== 설명

*pidload* opens a wxWidgets window that charts process CPU/I/O and selected
블록 장치 및 네트워크 트래픽.
샘플은 *--간격*마다 수집됩니다. *--window*는 기본 표시를 설정합니다.
스팬. 세션 기록은 메모리에 보관됩니다. 드래그하여 이동하고 마우스 휠을 사용하세요.
확대/축소합니다(모든 차트는 동일한 시간 보기를 공유합니다). 차트가 하나 이상 표시됩니다.
X축의 경과 시간 레이블입니다.

*보기 → 곡선 표시*는 세그먼트, 2차 또는 쌍삼차 보간을 선택합니다.
네트워크 차트에서 컨텍스트 메뉴 *표시 단위*는 원시 크기,
페이로드 크기(와이어 바이트에서 이더넷 헤더 추정치를 뺀 값) 및 패킷 수.

각 _NAME_은 프로세스를 선택합니다. 일치는 pid, 실행 파일 이름,
실행 파일 경로, 창 제목, glob 문자(*`*`*, *`?`*) 포함
실행 파일 이름, 경로 및 창 제목.
일반 이름은 전체 단어로 포함된 창 제목과도 일치합니다.
(대소문자를 구분하지 않음) `editor`는 `/bin/editor` 및 제목이 붙은 창과 일치할 수 있습니다.
``어떤 편집자``.

일치하는 여러 프로세스는 서로 다른 선 스타일(실선, 점선, 점선 등)을 사용합니다.
10가지 스타일을 사용한 후 재사용). 프로세스 차트에는 다음에 대한 별도의 프로세스 범례가 표시됩니다.
각 프로세스를 전환합니다.

*--output*이 설정되면 모니터링되는 각 엔터티가 해당 디렉터리에 기록됩니다.
(간격당 한 줄). 프로세스 로그의 이름은 _NAME_._PID_`.log`입니다.

=== 기록 필드

*netdev* (_IFACE_`.log`)::
`; 인바운드 아웃바운드가 떨어졌습니다`

*block device* (_DEV_`.log`)::
`; 읽기 쓰기`(`/proc/diskstats`의 바이트; 섹터 × 512)

*address* (_ADDR_`.log`)::
`; 인바운드 아웃바운드`

*process* (_NAME_._PID_`.log`)::
`; cpu_pct 읽기 쓰기`

*cpu* (`cpu.log`)::
`; 전체 코어0 …`

*memory* (`memory.log`)::
`; Used_kb avail_kb 스왑_used_kb`

*threads* (_NAME_._PID_`.threads.log` or `threads.log`)::
`; 살아있어 기다려 total_opened`

*fds* (_NAME_._PID_`.fds.log`)::
`; open_fds`

*connections* (_NAME_._PID_`.conn.log` or `connections.log`)::
`; 살아있어 기다려 총`

== 옵션

*-d, --dev* _DEVICE_::
블록 장치 I/O를 모니터링합니다. 반복 가능.

*-i, --iface* _NETDEV_::
네트워크 인터페이스 또는 '모두'를 모니터링합니다. 반복 가능.

*-a, --addr* _NETADDR_::
IPv4/IPv6 주소에 대한 트래픽을 모니터링합니다. 반복 가능.

*-c, --cpu*::
차트 시스템 CPU(전체 및 각 코어)

*-m, --memory*::
차트 시스템 메모리 및 스왑.

*-T, --threads*::
차트 스레드 수: 현재 활성 상태, 대기 중(실행 중이 아님) 및 총 고유 수
  세션 중에 스레드가 열렸습니다. _NAME_이 없으면 시스템 전체의 합계를 차트로 표시합니다.

*-F, --numfd*::
일치하는 프로세스에 대한 열린 파일 설명자 수를 차트로 표시합니다.

*-C, --connections*::
차트 TCP/UDP 연결 수: 활성(설정됨/현재), 대기(FIN/
  TIME_WAIT / …) 및 총 고유 소켓이 표시됩니다. _NAME_이 없으면 차트
  시스템 전체 `/proc/net` 소켓.

*-t, --interval* _D_::
샘플 기간(기본값: `2s`). 단위: `ms`, `s`/`sec`(기본값), `m`/`min`, `h`.

*-w, --window* _D_::
기본 표시 시간 범위(기본값: `3min`). 간격 이상이어야 합니다.
  전체 세션 기록은 메모리에 유지됩니다. 드래그하여 이동하고 마우스를 사용하세요.
  확대/축소할 휠입니다(모든 차트에서 공유됨).

*-o, --output* _PATH_::
간격 로그용 디렉터리(필요한 경우 생성됨)

*-v, --verbose*::
로깅의 자세한 정도를 높입니다.

*-q, --quiet*::
로깅의 자세한 정도를 줄입니다.

*-h, --help*::
사용량 요약을 인쇄하고 성공적으로 종료합니다.

*--version*::
버전 및 라이센스 정보를 인쇄하고 성공적으로 종료합니다.

== 예제

....
pidload editor
pidload -c -m -o /tmp/pl -t 1s '*term*' firefox
pidload -d nvme0n1 -i lo 1234
....
