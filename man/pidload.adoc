== Name

pidload - concatenate files to standard output

== Synopsis

*pidload* [_OPTION_]... [_FILE_]...

== Description

Copy each _FILE_ to standard output in order.
If _FILE_ is a single dash (*-*), read standard input at that position.
If no _FILE_ is given, read standard input once.

*pidload* is similar in spirit to *cat*(1): it writes the concatenation of
inputs to standard output.

== Options

*-v, --verbose*::
  Print each file name (or ``standard input`` for *-*) to standard error
  before copying that input.
  Repeat for more verbose logging.

*-q, --quiet*::
  Suppress messages that would be printed by *--verbose*.
  If both *--verbose* and *--quiet* are given, *--quiet* wins.

*-h, --help*::
  Print a usage summary and exit successfully.

*--version*::
  Print version and license information and exit successfully.

== Exit status

*0*::
  Success.

*1*::
  An error occurred (invalid options, unreadable file, or I/O error).
