== 名前

pidload - プロセス負荷とデバイス／ネットワークトラフィックを監視する

== 書式

*pidload* [_OPTION_]... [_NAME_]...

== 説明

*pidload* opens a wxWidgets window that charts process CPU/I/O and selected
デバイスとネットワークのトラフィックをブロックします。
サンプルは *--interval* ごとに取得されます。 *--window* はデフォルトの表示を設定します
スパン。セッション履歴はメモリに保存されます。ドラッグしてパンし、マウス ホイールを使用します。
ズームします (すべてのチャートが同じ時間ビューを共有します)。少なくとも 1 つのグラフが示す
X 軸の経過時間ラベル。

*View → Display Curve* は、セグメント補間、ベジェ補間、または双三次補間を選択します。
ネットワーク チャートでは、コンテキスト メニュー *表示単位* で生のサイズを切り替えます。
ペイロード サイズ (ワイヤ バイトからイーサネット ヘッダーの推定値を差し引いたもの)、およびパケット数。

ビューのレイアウトと表示トグル（有効なチャート、凡例、Y 対数、表示方式、
曲線スタイル、更新間隔、ウィンドウ形状、AUI ペイン配置）は、_NAME_
の組み合わせごとに `$XDG_CONFIG_HOME/pidload/<key>.state`
（既定は `~/.config/pidload/`）へ保存されます。キーは各 _NAME_ を
`path …` / `pid …` / `glob …` に分類した UTF-8 文字列（カンマ区切り）の
SHA-1 です。*-c* / *-i* / *-t* などの明示的な CLI フラグは、その実行で
保存値より優先されます。

各 _NAME_ はプロセスを選択します。マッチングは次のように試行されます: pid、実行可能ファイル名、
実行可能ファイルのパス、ウィンドウ タイトル、グロブ文字 (*`*`*、*`?`*) を含む
実行可能ファイルの名前、パス、ウィンドウのタイトル。
プレーンな名前は、その名前を単語全体として含むウィンドウ タイトルにも一致します。
(大文字と小文字は区別されません)、そのため `editor` は `/bin/editor` およびタイトルのウィンドウと一致します。
「ある編集者」。

複数の一致したプロセスは、異なる線スタイル (実線、破線、点線など) を使用します。
10 のスタイルを再利用)。プロセス チャートには、別のプロセス凡例が表示されます。
各プロセスを切り替えます。

*--output* が設定されている場合、各監視対象エンティティはそのディレクトリの下に記録されます
(間隔ごとに 1 行)。プロセス ログの名前は _NAME_._PID_`.log` です。

=== 記録フィールド

*netdev* (_IFACE_`.log`)::
`;インバウンド・アウトバウンドはドロップされました`

*block device* (_DEV_`.log`)::
`;読み取り書き込み` (バイト; `/proc/diskstats` からのセクター × 512)

*address* (_ADDR_`.log`)::
`;インバウンドアウトバウンド

*process* (_NAME_._PID_`.log`)::
`; cpu_pct 読み取り書き込み`

*cpu* (`cpu.log`)::
`;全体的なコア0 …`

*memory* (`memory.log`)::
`; used_kb avail_kb swap_used_kb`

*threads* (_NAME_._PID_`.threads.log` or `threads.log`)::
`;生存待機 total_opened`

*fds* (_NAME_._PID_`.fds.log`)::
`; open_fds`

*connections* (_NAME_._PID_`.conn.log` or `connections.log`)::
`;生存待機合計`

== オプション

*-d, --dev* _DEVICE_::
ブロックデバイスの I/O を監視します。再現可能。

*-i, --iface* _NETDEV_::
ネットワーク インターフェイス、つまり「すべて」を監視します。再現可能。

*-a, --addr* _NETADDR_::
IPv4/IPv6 アドレスのトラフィックを監視します。再現可能。

*-c, --cpu*::
システム CPU (全体および各コア) をグラフ化します。

*-m, --memory*::
システム メモリとスワップをグラフ化します。

*-T, --threads*::
チャートのスレッド数: 現在アクティブ、待機中 (非実行)、および一意の合計
  セッション中に開かれたスレッド。 _NAME_ を指定しないと、システム全体の合計がグラフ化されます。

*-F, --numfd*::
一致したプロセスの開いているファイル記述子の数をグラフ化します。

*-C, --connections*::
TCP/UDP 接続数のグラフ: 生存 (確立 / 存在)、待機 (FIN /
  TIME_WAIT / …)、および確認された一意のソケットの合計。 _NAME_ がない場合、グラフ
  システム全体の `/proc/net` ソケット。

*-t, --interval* _D_::
サンプル期間 (デフォルト: `2s`)。単位: `ms`、`s`/`sec` (デフォルト)、`m`/`min`、`h`。

*-w, --window* _D_::
デフォルトの表示時間範囲 (デフォルト: `3min`)。 ≥ 間隔である必要があります。
  完全なセッション履歴はメモリに保持されます。ドラッグしてパンし、マウスを使用します
  ホイールを使用してズームします (すべてのチャートで共有)。

*-o, --output* _PATH_::
間隔ログのディレクトリ (必要に応じて作成されます)。

*-v, --verbose*::
ログの詳細度を高めます。

*-q, --quiet*::
ログの冗長性を減らします。

*-h, --help*::
使用状況の概要を出力し、正常に終了します。

*--version*::
バージョンとライセンス情報を出力し、正常に終了します。

== 例

....
pidload editor
pidload -c -m -o /tmp/pl -t 1s '*term*' firefox
pidload -d nvme0n1 -i lo 1234
....

== 終了ステータス

*0*::
成功 (*--help* / *--version* を含む)。

*1*::
無効なオプションまたは起動失敗。
